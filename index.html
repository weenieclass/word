• 용언의 어간(예: 먹-, 웃-): 혼자 쓸 수 없지만 실질적 뜻이 있음 $\rightarrow$ 의존 + 실질

• 조사(예: 이/가, 은/는): 홀로 쓸 수 없고 문법적 관계만 표시 $\rightarrow$ 의존 + 형식

분류할 형태소 카드를 선택하거나 드래그하세요
자립 + 실질 형태소 명사, 대명사, 수사, 관형사, 부사, 감탄사

혼자 쓸 수 있으며 구체적인 사물이나 상태의 뜻을 가짐

자립 + 형식 형태소 국어에 존재 안 함

자립 형태소는 모두 실질적 의미를 가지고 있음

의존 + 실질 형태소 ★ 용언의 어간

의존 + 형식(문법) 형태소 조사, 어미, 접사

탐구 질문: 스스로 확인하기

질문 1. '풋사과'의 '풋-'은 강한 뜻이 느껴지는데 왜 어근이 아닐까요?

'풋-'은 '덜 익은'이라는 특정한 뜻을 덧붙여주지만, 혼자서 독립적으로 쓰일 수 없으며 항상 명사 앞에만 붙는 접두사이기 때문입니다. 따라서 파생어입니다.

질문 2. '지우개'에서 '지우-'는 용언의 어간인데 어근이 될 수 있나요?

네! 용언의 어간은 실질적 의미를 지니고 있으므로 단어를 형성할 때 어근의 역할을 합니다. 여기에 도구를 만드는 접미사 '-개'가 붙어 명사 파생어가 됩니다.
